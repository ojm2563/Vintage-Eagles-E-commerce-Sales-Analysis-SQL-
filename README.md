**# Vintage-Eagles-E-commerce-Sales-Analysis-SQL-**
This project uses SQL Server to analyse historical sales and purchasing data from Vintage Eagles, an e-commerce resale business operating between April 2023 and May 2025.  
The objective is to investigate business performance, identify sales trends and compare commercial performance across eBay and Vinted.

**The project uses four datasets:**
eBay sales
Vinted sales
Purchasing records
Operating expenses

**Tools**
Microsoft SQL Server
SQL
Visual Studio Code
Power BI (planned)
